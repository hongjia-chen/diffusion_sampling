Remasking with SDAR-8B

exp05 let Dream-7B check and edit SDAR-1.7B’s answers, and most edits it made were style fixes (a leading space, \r\n) rather than corrections. exp06 re-runs that recipe with an aligned verifier, SDAR-8B, which has the same tokenizer, chat template and whitespace habits (cross8b). SDAR-1.7B proposes; SDAR-8B accepts a prefix under the verifier-only ratio, with no veto. After each block, it re-scores every committed token with that token masked, and replaces one of the four least probable that it would change. The swap run reverses the roles as a control. Every comparison below is paired: the same 100 tasks, the same δ, with remasking on and off.

Fixed / broken pools δ=0.1 and δ=1 for each experiment. The p-value treats the two δ as independent (they share tasks), so it overstates significance.

What kind of edit it makes

Decoding is deterministic, so the first token where a remask run and its counterfactual differ is the first edit that survives into the answer. That is the only view exp05’s records allow, so all three experiments are classified the same way here. Grey kinds change only whitespace; coloured kinds change content.
